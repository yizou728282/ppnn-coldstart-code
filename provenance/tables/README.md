# Saved table exports

The five CSV files and fifteen LaTeX table fragments preserve the numerical table exports from publication snapshot `395ba753102c5a2ebf9503b9bd6a212dce05060f`, where their paths were under `paper/tables/`. They are stored here with the numerical provenance records so that the manuscript directory is not required to inspect them.

`SHA256SUMS.txt` records the file identities. Original paths, source commits and hashes are also recorded in `provenance/file_origins.json`. These exports are stored results; regenerating them is a separate operation that may require predictions and provider observation data.
